# E-Commerce Conversion Funnel Analysis 📊

## Project Overview

This project is an interactive Power BI dashboard designed to analyze
the e-commerce customer journey from website visits to final purchases.

The dashboard provides insights into conversion performance, revenue,
traffic channels, product categories, and regional performance.

## Dashboard Pages

### Page 1 – E-Commerce Conversion Funnel Overview

The first page focuses on the overall customer conversion funnel.

Key metrics include:

- Total Visitors
- Product Views
- Add to Cart
- Purchases
- Conversion Rate
- Total Revenue
- Revenue by Product Category
- Bounce vs Non-Bounce Sessions
- Conversion Rate by Product Category

### Page 2 – Channel & Regional Analysis

The second page provides deeper analysis of traffic sources,
regions, revenue, and customer conversions.

It includes:

- Purchase Distribution by Product Category
- Regional Performance
- Conversion Rate
- Traffic Distribution by Channel
- Revenue by Channel
- Channel Revenue vs Conversion Rate
- Channel-wise visitor and purchase analysis

## Project Objective

The objective of this project is to understand customer behavior
through different stages of the e-commerce funnel and identify
patterns in conversions, revenue, traffic sources, product
categories, and regions.

## Conclusion

This project demonstrates how Power BI can be used to transform
e-commerce data into an interactive business intelligence dashboard
and provide meaningful insights into customer conversion and revenue
performance.
